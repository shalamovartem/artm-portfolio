# artm.sh — портфолио Артёма Шаламова

Портфолио с конструктором карточек, редактором разделов и страниц, визуальным Markdown-редактором и локальной авторизацией. Next.js 16, React 19, TypeScript. Текущая версия: 14 октября 2026.

## Локальная разработка

Для разработки используйте Node.js 22.13 или новее.

```sh
npm ci
cp .env.example .env.local
```

Для локального запуска измените `PUBLIC_ORIGIN` в `.env.local` на `http://localhost:3000`.

```sh
npm run admin
npm run dev
```

Создайте свой логин и пароль интерактивно. Откройте http://localhost:3000. Начальные материалы находятся в `lib/initial.json` и `lib/projects.json`. После сохранения редактор записывает данные в `data/content.json`.

## Сборка и запуск

```sh
npm run build
npm start
```

Продакшен-сборка проверена на Node.js 22.9.0. На SprintHost используется `server.cjs` через Phusion Passenger. Настройки — в `deploy/htaccess.example`, инструкция по установке готового обновления — в `deploy/UPDATE-2026-10-14.md`.

Этот репозиторий содержит исходники, а не готовую `.next` и не `node_modules`. Архив готового обновления передан отдельно. На хостинге с ограниченными ресурсами используйте готовый архив: повторная установка npm там ранее завершалась принудительно.

## Данные и настройки

- `data/content.json` — опубликованная версия и черновик.
- `data/admin.json` — хеш пароля и секрет сессий.
- Загруженные изображения и резервные копии хранятся в `data`.
- `PUBLIC_ORIGIN` — основной адрес, в продакшене `https://artm.sh`.
- `DATA_DIR` — необязательный путь к постоянному хранилищу.

Папка `data`, пароли, `.env.local`, служебные файлы и история старого рабочего репозитория в GitHub не загружаются. При обновлении хостинга сохраняйте `data` и `.env.local`. Репозиторий не заменяет резервную копию данных сайта.

## Проверки

`npm run build` проверяет TypeScript и собирает сайт. `python3 tests/editor-update-check.py` запускает отдельный локальный сервер с временной папкой данных и случайным тестовым паролем. Проверяет вход, CSRF, разделы, страницы в корне, иконки, координаты и сохранение темы. Рабочую папку `data` тест не использует. Требуется предварительная сборка и Python 3.

`npm run format:check` проверяет форматирование, `npm run typecheck` — типы и неиспользуемый код.

## Структура исходников

- `app/portfolio.tsx` — главная страница и конструктор карточек.
- `app/project-editor.tsx`, `app/markdown.tsx` — редакторы страниц и текста.
- `app/live-map.tsx`, `app/map-editor.tsx` — карта, погода и выбор места.
- `app/card-icon.tsx` — общий каталог иконок.
- `app/use-theme.ts`, `lib/theme.ts` — предпочтение темы в браузере и на сервере.
- `lib/document.ts` — схема данных, значения по умолчанию и совместимость старых документов.
- `lib/storage.ts`, `lib/auth.ts` — файловое хранилище и вход администратора.
- `app/api/places`, `app/api/weather` — поиск населённых пунктов и погода по координатам.

Иконки брендов: [Simple Icons](https://simpleicons.org), лицензия рядом с SVG в `public/icons`. Поиск городов: [Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api), [погода по координатам](https://open-meteo.com/en/docs). Ключ API для этих возможностей не требуется.
