# Открытое портфолио с редактором

[Сайт автора](https://artm.sh) · [GNU GPL v3](LICENSE) · [Установка на сервер](deploy/SERVER.md) · [Сторонние лицензии](THIRD_PARTY.md)

Next.js 16, React 19 и TypeScript. Конструктор карточек, разделы, страницы проектов и обычные страницы в корне сайта, визуальный Markdown-редактор, HTML-страницы, фотографии, карта с погодой и локальный вход администратора. Контент хранится в файлах: отдельная база данных не нужна.

## Запустить на своём компьютере

Требуются Git, Node.js 22.13+ (ветка 22 LTS) и npm. Python 3 нужен только для интеграционных тестов.

```sh
git clone https://github.com/shalamovartem/artm-portfolio.git
cd artm-portfolio
npm ci
cp .env.example .env.local
```

В `.env.local` установите `PUBLIC_ORIGIN=http://localhost:3000`. Затем создайте собственный аккаунт администратора и запустите сайт:

```sh
npm run admin
npm run dev
```

Откройте http://localhost:3000. `npm run admin` интерактивно спрашивает логин и пароль (минимум 12 символов). Пароль при вводе не отображается. Повторный запуск заменяет аккаунт и завершает прежние сеансы входа. В репозитории нет готового аккаунта.

## Собрать рабочую версию

```sh
npm run build
npm start
```

Сервер использует порт 3000, если `PORT` не задан в окружении процесса. `HOST` позволяет задать адрес прослушивания. Пример: `HOST=127.0.0.1 PORT=3000 npm start`. Для публичного сайта нужны постоянное хранилище, HTTPS и перезапуск процесса при сбоях — см. [инструкцию для Linux-сервера](deploy/SERVER.md).

## Что и где редактировать

Нажмите «Конструктор» и войдите своим логином. Сначала изменения сохраняются в черновик; «Опубликовать» делает их видимыми посетителям. «Сохранить» не публикует изменения.

| Что изменить                                         | Где найти                                                                                    |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Название вкладки, приветствие, имя, описание, аватар | Главная → Конструктор → Страница                                                             |
| Логотип, фавикон, тема по умолчанию и акцент         | Настройки страницы                                                                           |
| Названия и порядок разделов                          | Страница → Разделы страницы                                                                  |
| Описание конкретного раздела                         | Открыть раздел при включённом конструкторе                                                   |
| Нижняя подпись и имя в копирайте                     | Внизу настроек страницы; год вычисляется автоматически                                       |
| Текст, ссылка, иконка, размер, цвет карточки         | Нажать карточку в конструкторе                                                               |
| Порядок карточек                                     | Перетащить карточку на нужное место                                                          |
| Место, координаты, масштаб и погода                  | Карточка типа «Место» → Место на карте                                                       |
| Категория PROJECT / …                                | Настройки карточки проекта или категория самой страницы проекта                              |
| Страница проекта или страница в корне                | «Редактировать страницы» → выбрать или создать; расположение `/projects/адрес` либо `/адрес` |
| Текст страницы                                       | Редактор страницы → визуальный режим или Markdown; можно развернуть редактор                 |
| Собственная HTML-страница                            | При создании выбрать тип HTML; доступны HTML и цвета оставшихся элементов                    |
| Удаление страницы                                    | В редакторе выбранной страницы                                                               |

Ссылка карточки может быть внешней (`https://…`), на страницу (`/about`) или раздел (`/?section=photos`). Для разделов есть выпадающий список. Фото без ссылки открывается для просмотра; при заданной ссылке выполняется переход. Для проверки узкой компоновки включите «Мобильный вид» в редакторе.

## Адаптировать проект для себя

Замените имя, контакты, аватар, логотип, фотографии и тексты через редактор. Начальные материалы служат примером и не являются свободной библиотекой фотографий или логотипов.

До первого сохранения начальные данные берутся из `lib/initial.json`, а набор проектов для старого формата — из `lib/projects.json`. После сохранения источником становится `data/content.json`: изменения JSON в `lib` не перезаписывают существующий сайт. Не удаляйте рабочую папку `data`, чтобы применить новый дизайн.

| Файл                                         | Назначение                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------------- |
| `app/portfolio.tsx`                          | Главная, разделы и конструктор карточек                                             |
| `app/globals.css`                            | Цвета, сетки, адаптивность, анимации и стили редакторов                             |
| `app/projects/[slug]/project-view.tsx`       | Внешний вид обычных и HTML-страниц                                                  |
| `app/project-editor.tsx`, `app/markdown.tsx` | Поля страницы, визуальный редактор и Markdown                                       |
| `app/project-picker.tsx`                     | Выбор и создание страниц                                                            |
| `app/card-icon.tsx`, `public/icons`          | Каталог и SVG иконок                                                                |
| `app/live-map.tsx`, `app/map-editor.tsx`     | Карта, анимации и выбор места                                                       |
| `app/api/weather`, `app/api/places`          | Серверные запросы погоды и поиска городов                                           |
| `lib/document.ts`                            | Схема, проверка и миграции данных; новые поля добавляйте со значениями по умолчанию |
| `lib/storage.ts`, `lib/auth.ts`              | Хранилище, вход и защита запросов                                                   |
| `lib/links.ts`                               | Обработка ссылок; при форке пересмотрите список доменов автора                      |
| `app/open-source-links.tsx`                  | Ссылка на исходники в подвале; укажите свой форк при распространении изменений      |
| `app/licenses/page.tsx`, `THIRD_PARTY.md`    | Страница лицензий и описание сторонних материалов                                   |

## Настройки и данные

Пример окружения — `.env.example`. `.env.local` загружается Next.js и командой создания администратора. Для запуска сервера `PORT` и `HOST` задавайте в окружении процесса (например, в systemd).

- `PUBLIC_ORIGIN` — точный публичный адрес с протоколом, например `https://portfolio.example.com`. Используется для проверки источника запросов. В локальной разработке — `http://localhost:3000`.
- `DATA_DIR` — абсолютный путь к постоянной папке данных. По умолчанию `data` в каталоге проекта.
- `data/content.json` — опубликованное содержимое и черновик; `data/admin.json` — хеш пароля и секрет сессии. Загруженные изображения и история сохранений также находятся в `data`.

Папка данных и файлы окружения не должны быть доступны через веб-сервер или попадать в Git. Делайте резервные копии всего `DATA_DIR` и настроек окружения. Экспорт JSON в редакторе не включает файлы загруженных изображений. Файловое хранилище рассчитано на один экземпляр приложения с постоянным диском, а не на бессостояние serverless или несколько независимых реплик.

## Проверить изменения

```sh
npm run format:check
npm run typecheck
npm run build
npm run test:integration
```

Интеграционная проверка требует готовой сборки и Python 3, создаёт отдельный сервер, временную папку и случайный тестовый аккаунт. Рабочие данные не затрагиваются.

После изменения зависимостей выполните `npm run licenses` и сохраните обновлённый каталог и уведомления вместе с `package-lock.json`.
